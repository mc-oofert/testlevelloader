# testlevelloader
wuckle level asset bundle loader intended for testing
Requires BepInEx 5 (manually installed if youre compiling)
## how do i use this
by default bundles are gotten from a CustomLevels folder in the plugins folder (you need to make one)
Press F7 to open the menu
Pressing Reload All Bundles unloads current bundles, looks for bundles again, then loads them. Good for testing bundle changes without restarting the game
